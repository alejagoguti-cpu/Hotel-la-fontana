# Hotel La Fontana · Recorrido con flechas

Recorrido por el entorno del Hotel Estelar La Fontana (Bogotá) con panorámicas 360° renderizadas en Unreal Engine 5 + Cesium
(edificios de Catastro con fachadas, árboles 3D y Google Photorealistic 3D Tiles), en una cuadrícula de 5 × 5 puntos cada 100 m, a 60 m de altura.

- ← → girar · ↑ ↓ avanzar / retroceder hacia donde se mira · arrastrar para mirar · rueda para acercar
- Página: https://alejagoguti-cpu.github.io/Hotel-la-fontana/  (`?n=n_<fila>_<col>` abre un punto; fila 0 = norte, col 0 = oeste)
- Giro con imágenes: https://alejagoguti-cpu.github.io/TLF/ · Panorámicas: https://alejagoguti-cpu.github.io/TLF-360/

El edificio del hotel que se está remodelando se reemplazará por el modelo de Revit cuando esté listo.

Imágenes 3D: Google · Render: Unreal Engine + Cesium
